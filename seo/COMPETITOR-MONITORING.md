# Competitor monitoring

## Current baseline

There is no verified direct-competitor set yet. Automated search results did not establish which listed pages are operating agencies, official platform properties, affiliates, or irrelevant results. Do not treat the domains in the research snapshot as endorsed or verified competitors.

## Monthly process

1. Search the same branded and non-branded query set from the intended country/language, logged out and on mobile/desktop.
2. Record date, location, query, result title, URL, page type, snippet, and whether the business/relationship is verified.
3. Compare content coverage and clarity—not scraped/copyable prose.
4. Use Search Console to assess the site's actual impressions and clicks; do not infer rank changes from one personalized SERP.
5. Add a candidate to the competitor list only after confirming it targets the same audience/need and is an operating organization.

## Query set

- Stripchat agency India
- Stripchat India agency
- Stripchat model registration India
- how to become a Stripchat creator in India
- creator privacy/safety questions relevant to the actual service

## Sources and limits

- Bing RSS is useful as a quick discovery snapshot, not a complete or stable SERP archive.
- Google results require manual review; the automated fetch in this environment was blocked by its JavaScript flow.
- Competitor traffic and backlinks require authorized Search Console access (for the agency's own site) or appropriately licensed third-party tools.
