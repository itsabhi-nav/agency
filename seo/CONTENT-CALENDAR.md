## Publishing checklist

- Answer the target question early and use precise, plain language.
- Add relevant citations to current official sources.
- Name a real reviewer/author only if they consent and their credentials are accurate.
- Link to `/help` or `/apply` only when contextually useful.
- Avoid explicit adult images, keyword-stuffed titles, false job-posting framing, and earnings promises.
- Add page metadata, canonical, and sitemap entry only when there is a real public route with unique value.
